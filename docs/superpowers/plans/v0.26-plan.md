## Key APIs (reference)

- `updateHeat(completed, total)` — sets --heat, calls updateMotivation()
- `showToast(msg, sub)` — top-banner toast
- `calcStreak()` / `calcHabitStreak(id)` — streaks
- `isPlaceholder` — true in demo mode

## CSS Token Reference (unified, what index.html uses)
```
--gold / --goldb / --goldbor    — gold accent colors
--blood / --bloodb / --bloodbor — blood/danger colors
--ct / --cts / --ctd / --ctdd   — text hierarchy (hi/secondary/dim/dimmer)
--cs / --cs2                    — card surface colors
--cbor / --cborl                — card borders
--heat / --heat-overlay-alpha   — heat system
--gold-true / --gold-glow       — true gold (not heat-shifted)
--bg                            — background
--card-shadow / --ts            — shadows/text-shadows
--hm1/--hm2/--hm3/--hm4        — heatmap cell opacity levels
```
